# CoS 3.0.0

CoS 3.0 establishes an independent durable-runtime line in `MurphyHoops/CoS`.

## Highlights

- Persistent local missions are the durable unit of work; provider conversations are replaceable executors.
- Generic Long-Run Runtime adds execution epochs, durable work obligations, certified progress and local external-wait supervision.
- `session_wait` supports direct invocation and code-mode terminal yield when a host hides the direct tool.
- Self-Healing can migrate Prime and worker executors while preserving session identity and mutation-safety fences.
- Compact & Resume, Goal/Loop, worker revival and wait continuations share the same durable authority model.
- Stale or superseded executors are fenced from local tools; ambiguous mutations are never blindly replayed.

## Repository policy

This repository is the canonical CoS 3.x source and direct development line. External changes are reviewed against current CoS invariants and ported selectively when useful.

CoS 3.x began from the open-source **Chat On Steroids** project created by [@totec448-spec](https://github.com/totec448-spec). Thank you for the original foundation; historical provenance and legally required notices remain preserved.

## Updating

Install the matching 3.0.0 app and companion extension together. Refresh the CoS custom app/tool schema in ChatGPT after updating when prompted.
