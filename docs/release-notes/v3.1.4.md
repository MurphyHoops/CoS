## 3.1.4: Cross-platform release hardening

CoS 3.1.4 carries the companion-update self-healing behavior introduced in 3.1.3 and fixes the
release-pipeline issues that prevented 3.1.3 from becoming a published GitHub Release.

The Windows verification failures were test portability defects rather than runtime regressions:
the GitHub CLI PATH test forced macOS executable semantics while running on Windows, and four Goal
durability tests compared a Windows state path against a string assembled with POSIX separators.
Those tests now use the host platform's executable/path rules, so the same durability and discovery
contracts are exercised correctly on both Windows architectures.

The native-source candidate job also exposed GNOME GitLab intermittently rejecting Node/Undici
downloads of the reviewed GVDB archive with HTTP 406, including one runner that rejected all five
bounded attempts. Source packaging now uses an explicit verifier User-Agent, bounded retry/backoff,
lower concurrency, and—only after retryable fetch failures are exhausted—a system `curl` fallback
against the exact same reviewed URL. The fallback is transport redundancy, not a mirror or alternate
source. It makes one bounded second-transport attempt rather than layering another retry loop over
the five Node attempts. Every downloaded byte is still required to match the reviewed size and
SHA-256 inventory before it can enter the source archive, and non-retryable/integrity failures never
enter fallback.

The full release matrix also exposed a completion-remount race on macOS x64. React can detach an
assistant section one mutation before its completed replacement is mounted; the chronological stream
used to discard the detached presentation record immediately even though the next paint needs that
exact record to preserve disclosure identity and open state. Detached records are now retained only
through the already-bounded remount grace and can still be reclaimed only through the existing exact
call/website-identity fences. A regression forces the intermediate detached paint and separately
proves that an unreclaimed record expires at the grace boundary.

The browser companion update model itself is unchanged from 3.1.3: CoS refreshes the stable
unpacked-extension folder before bridge startup, keeps the Chrome-visible root in place during
normal updates, and lets a stale worker perform one build-ID-fenced self-reload. Existing ChatGPT
tabs are then repaired by the startup recovery path; a normal page refresh remains sufficient if a
tab still displays stale page state.

App and companion are version 3.1.4. Bridge protocol remains 15.
