# CoS 3.1.17 — Restart-safe provider history limits

This Classic 3.x update builds on `main@9a9c01f` and does not change Next WebRuntime.

## Change

ChatGPT conversation-history HTTP 429 observations with bounded `Retry-After` values now durably record the exact conversation and deadline before the browser observation is acknowledged. Bridge startup restores those deadlines before any recovered browser repair is dispatched or claimed. A corrupted ledger holds automatic browser repairs rather than assuming rate limiting is over. Normal chat, explicit user Stop and local MCP work do not need this recovery permit.

The app and unpacked companion build IDs advance together to `cos-3.1.17-history-pressure-v1`; bridge protocol remains 15.
