## 2.1.12: Model picker compatibility


> **Historical — pre-CoS 3.0.** This document is preserved as engineering/provenance evidence. It does **not** define current runtime behavior. Current architecture is defined by docs/architecture.md and AGENTS.md. Historical version numbers, repository links, PRs, incidents and implementation assumptions are intentionally retained as facts from that period.

- Supports effort-only picker labels such as Medium, High and Extra High without requiring the old 5.6 prefix.
- Handles model-version rows with retirement captions, including the new leaving-date message.
- Recognizes the closed `6 Pro` label while validating the actual provider model identity.
- Preserves account-denial checks, exact model/effort confirmation and the original selection after discovery.

**Reload the companion extension and refresh your ChatGPT tabs after updating, then refresh the app's model list.**
